# Feature Inventory: Next-Gen Creative Blog Platform

## Overview of Core Features
- **F1: 3D Interactive Hero Canvas & Spatial Physics**: Three.js WebGL spatial geometry responding to mouse coordinates with real-time lighting shaders.
- **F2: Kinetic Navigation, Magnetic Physics & Smooth Scrolling**: Lenis inertial scrolling coupled with GSAP spring-physics magnetic button attraction and custom cursor tracking.
- **F3: Rich Draft & Markdown Story Publishing Engine**: Full authoring studio with automated Nanoid slug generation, multi-tag categorization, and Cloudinary cover uploads.
- **F4: Social Community Graph, Threaded Comments & Activity Notifications**: Interactive applause/like counters, nested comment replies, and automated author notification dispatch.
- **F5: Cryptographic User Authentication & JWT Identity Protection**: Salted bcrypt password hashing, stateless HS256 JWT tokens, and role-based author resource protection.

## Say It Out Loud (Feature Summary)
"When explaining this project to an interviewer, I emphasize that it is not just another basic CRUD blog. I designed it to demonstrate how high-performance graphics like WebGL and Three.js can coexist harmoniously with a robust Node.js and MongoDB backend. Readers enjoy a 60-frame-per-second interactive experience with smooth scrolling and reactive 3D visuals, while creators have a clean, secure publishing workflow with automated CDN image processing and fast slug-based routing."
