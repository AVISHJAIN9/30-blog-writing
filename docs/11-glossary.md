# Technical Glossary

- **Three.js**: A cross-browser JavaScript library and API used to create and display animated 3D computer graphics in a web browser using WebGL.
- **React Three Fiber (R3F)**: A React renderer for Three.js that brings declarative component design to WebGL scene graphs.
- **Lenis**: A lightweight, high-performance smooth scroll library that provides inertial momentum scrolling without hijacking native accessibility.
- **GSAP**: GreenSock Animation Platform, a high-performance JavaScript animation library for scripting complex UI tweens.
- **Nanoid**: A tiny, secure, URL-friendly unique string ID generator for JavaScript.
- **JWT (JSON Web Token)**: A compact, URL-safe means of representing claims to be transferred between two parties, cryptographically signed with HS256.
