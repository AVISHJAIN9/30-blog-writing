### 1. What is MERN Interactive Publishing Platform?
Full-stack publishing and content management application with Markdown editing and role access.

### 2. What technology stack does it use?
Built with Node.js (Express, MongoDB Atlas), React / JavaScript.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/30-blog-writing/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
